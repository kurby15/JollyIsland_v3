
  # JollyIsland Management System

  This is a code bundle for JollyIsland Management System. The original project is available at https://www.figma.com/design/EQjZnqs4WMupeOaui5TkCm/JollyIsland-Management-System.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  ## InfinityFree Deployment

  Build the app with `npm run build`, upload the `dist` contents to `public_html`, and keep the Firebase Auth authorized domain set to your InfinityFree domain.
